# Support

StreamDeck Control is pre-release software maintained on a best-effort basis. No
uptime, response-time, compatibility, or live-production support guarantee is
provided.

## Before requesting help

1. Review [installation](docs/installation.md) and
   [troubleshooting](docs/troubleshooting.md).
2. Reproduce with the latest supported desktop build and matching reference
   firmware.
3. Search open and closed GitHub issues.
4. Remove credentials and personal information from every attachment.

Use the **Bug report** issue form for reproducible defects and **Feature request**
for proposals. General setup questions may use a GitHub discussion if Discussions
is enabled; otherwise open a clearly labeled issue.

Include application and firmware versions, Windows and OBS versions, hardware
profile, exact steps, expected/actual behavior, and the smallest redacted log
excerpt that shows the failure. Do not upload the full user configuration by
default. Never include OBS passwords, OS credential-store exports, private keys,
API tokens, stream keys, or unrelated screen contents.

Security problems must follow [SECURITY.md](SECURITY.md), never a public support
issue. Hardware damage, electrical safety, certification, and custom PCB design
are outside community support scope.
